# TypeScript — упражнения на основе твоего проекта

Мягкий вход в TypeScript. Ты уже почитала теорию — теперь потренируемся на
данных и компонентах, которые ты **сама уже писала** в этом приложении с фильмами.

## Как это работает

Каждое упражнение — это файл с задачами. В коде есть пометки `// TODO` — только
их и нужно менять. Блок «Проверки — не трогай» внизу файла оставляй как есть:
он сам проверит, что ты всё сделала правильно.

Проверка одной командой:

```bash
npm install        # один раз, если ещё не ставила зависимости
npm run ts:check
```

- **Есть красные ошибки** → упражнение ещё не готово, смотри, на какую строку
  ругается TypeScript.
- **Ошибок нет** → всё верно! 🎉 Потом специально что-нибудь сломай (передай
  строку вместо числа) и посмотри, как TypeScript тебя ловит — это и есть вся суть.

💡 Удобнее всего в VS Code: ошибки подчёркиваются красным прямо в редакторе,
команду можно даже не запускать. Наведи курсор на подчёркивание — TS объяснит,
что не так.

## Порядок прохождения

Идём строго по номерам — сложность растёт плавно.

| #  | Файл                     | Тема                                          |
|----|--------------------------|-----------------------------------------------|
| 01 | `01-primitives.ts`       | типы у параметров и переменных                 |
| 02 | `02-objects-unions.ts`   | объекты, необязательные поля `?`, union `\|`   |
| 03 | `03-narrowing.ts`        | `string \| null`, приведение строки к числу    |
| 04 | `04-movie-types.ts`      | `interface Movie` — данные из TMDB             |
| 05 | `05-functions.ts`        | типизируем функции (`fetchMovies`, избранное)  |
| 06 | `06-button-props.tsx`    | пропсы React-компонента                        |
| 07 | `07-movie-card.tsx`      | всё вместе: карточка фильма                     |

## Зачем это тебе прямо сейчас

Упражнения 03 и 05 — про `string | null` и приведение страницы к числу.
Это ровно те места, где в приложении были баги **«Page 0»** и **«?search=null»**.
С типами TypeScript подсветил бы их ещё до запуска. Почувствуй разницу 🙂

## Для преподавателя

- Эталонные решения: папка `solutions/`. Проверить их: `npm run ts:check:solutions`
  (должно проходить без ошибок).
- Заготовки для ученицы намеренно «красные»: `tsc` ругается, пока не заполнены
  `// TODO`. Ошибки указывают прямо на нужные строки (`implicitly has an 'any'
  type`, отсутствующие поля, `Unused '@ts-expect-error'`).
- Конфиг `ts-exercises/tsconfig.json` изолирован и **не влияет** на сборку Vite.

### Полезные ресурсы (проверенные, бесплатные)

- **TypeScript Playground** — https://www.typescriptlang.org/play — песочница в
  браузере, ничего ставить не надо. Идеально для «поиграть с типами».
- **Официальный хендбук, «TypeScript for JavaScript Programmers»** —
  https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html
- **Total TypeScript — Beginner's Tutorial (Matt Pocock)** —
  https://www.totaltypescript.com/tutorials/beginners-typescript — бесплатный
  интерактивный курс из коротких упражнений «почини типы». Очень наглядно, тот же
  формат, что и здесь. На английском, но с минимумом текста.
- **Exercism, трек TypeScript** — https://exercism.org/tracks/typescript —
  бесплатные задачи с ревью от менторов, от простого к сложному.
- **type-challenges** — https://github.com/type-challenges/type-challenges —
  на будущее, когда база будет уверенной (там уже продвинутая магия типов).
