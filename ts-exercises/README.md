# TypeScript — упражнения на основе твоего проекта

Мягкий вход в TypeScript. Ты уже почитала теорию — теперь потренируемся на
данных и компонентах, которые ты **сама уже писала** в этом приложении с фильмами.

## Как это работает

Каждое упражнение — это файл с задачами. В коде есть пометки `// TODO` — только
их и нужно менять. Блок «Проверки — не трогай» внизу файла оставляй как есть:
он сам проверит, что ты всё сделала правильно.

Проверка одной командой:

```bash
npm install        # один раз, если ещё не ставила зависимости
npm run ts:check
```

- **Есть красные ошибки** → упражнение ещё не готово, смотри, на какую строку
  ругается TypeScript.
- **Ошибок нет** → всё верно


## Порядок прохождения

Идём строго по номерам — сложность растёт плавно.

| #  | Файл                     | Тема                                          |
|----|--------------------------|-----------------------------------------------|
| 01 | `01-primitives.ts`       | типы у параметров и переменных                 |
| 02 | `02-objects-unions.ts`   | объекты, необязательные поля `?`, union `\|`   |
| 03 | `03-narrowing.ts`        | `string \| null`, приведение строки к числу    |

## Блок 2 — следующий уровень

Основы уже позади. Дальше — темы, которые убирают дублирование и делают
типы «умными». Тот же формат: меняешь только `// TODO`, проверяешь `npm run ts:check`.

| #  | Файл                          | Тема                                              |
|----|-------------------------------|---------------------------------------------------|
| 08 | `08-generics.ts`              | дженерики `<T>` — один тип на любые данные          |
| 09 | `09-unknown.ts`              | `unknown` против `any` — безопасные данные          |
| 10 | `10-utility-types.ts`        | `Pick` / `Omit` / `Partial` — тип из типа           |
| 11 | `11-record.ts`              | `Record` и индексные сигнатуры (словари)            |
| 12 | `12-discriminated-unions.ts` | размеченные union + `never` — состояние запроса     |
| 13 | `13-keyof.ts`              | `keyof` и ограничения дженериков `extends`          |
| 14 | `14-typed-hook.tsx`        | капстоун: типизируем результат хука и компонент     |

Связка с твоим кодом: 11 — это `useGenres` (словарь id→жанр), 12 и 14 — это
`useMovies` с его `isLoading / isError / data`, но так, что TS не даст обратиться
к данным, пока не проверишь статус. А 09 честно чинит `as` из упражнения 05.
